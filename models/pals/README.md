# 3D-моделі попалів — форми 1, 2, 3

**У гру не підключено.** Це окремі файли для перегляду й доопрацювання (Blender, Polpal Studio).
Гра й далі будує попалів кодом (`site/src/modules/pal-models.js` + форми `pal-forms.js`); ці GLB вивантажені саме з цих моделей,
тож виглядають так само, як у грі. Підключати їх у гру — лише окремим рішенням.

- Формат: glTF 2.0 binary (`.glb`), одиниці — метри, «вгору» — +Y, морда дивиться в +Z, лапи на Y≈0.
- Розмір форми вже врахований: форма 2 — ×1.06, форма 3 — ×1.12.
- **Без контуру.** Темний контур у грі — це оболонка, яку видно лише зсередини; glTF так не вміє. У Blender — модифікатор Solidify з «Flip Normals» і чорним матеріалом, у грі — шейдер.
- **Без анімацій.** У грі попали рухаються кодом (хода, дихання, крила). У файлах — частини в позі спокою, згруповані за вузлами (голова, тулуб, лапи, крила, хвіст). Пухоклуб — зі скелетом (кістки збережено).
- **Без світіння.** Сяйво-спрайти (аура, іскри, шлейф Крилоші) у GLB не входять; матеріали з підсвіткою (вогонь, кристали, лід) мають emissive.
- Кожен файл перевірено повторним завантаженням (GLTFLoader three.js r128): частини, трикутники, межі, скінченні координати. Прев'ю в `previews/` відрендерені саме з повторно завантажених файлів (спереду, 3/4, збоку, ззаду); огляд усіх — `previews/_overview.png`.
