# Міражбр — кандидати моделей з Blender

**Статус: кандидати експортовано й перевірено в Blender і в three.js r128. У гру не підключено** (лише окремим рішенням).
Зібрано скриптом: `python ../build_pal.py -- mirazhbr all <тека>` (Blender 5.2 як модуль bpy), опис попала — `../specs/mirazhbr.py`, спільна бібліотека — `../lib/`.

- Файли: `mirazhbr_form1..3.glb` (тіло зі скелетом), `mirazhbr_fx.glb` (ефекти атак, показувати лише під час атаки), `.blend` до кожного,
  `mirazhbr_attacks.json` (кліп → назва атаки), `evolutions.png` (форми 1–3, 4 ракурси), `attacks.png` (по 5 кадрів кожної атаки, форма 3).
- Кліпи тіла (14): `idle` (з морганням), `walk`, `attack`, `happy`, `blink`, `atk_1`…`atk_9`. Кліпи ефектів: `atk_1`…`atk_9` — ті самі назви й тривалість.
- Ціль атак в ефектах: 2,6 м попереду (ближні — 1,7 м). Розмір форм: ×1,00 / ×1,06 / ×1,12.
